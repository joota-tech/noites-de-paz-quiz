# Noites de Paz - Quiz de vendas para marketing digital

Quiz interativo com perguntas persuasivas e página de vendas, criado para praticar estratégias de conversão em marketing digital.

🔗 **Projeto no ar:** https://noitedepaztm.lovable.app/

## Sobre o projeto

O usuário responde a uma sequência de perguntas pensadas para engajar e conduzir até uma página de vendas. A interface usa animações e navegação entre etapas para manter a experiência fluida. Nesta versão, a integração com checkout foi removida, e o projeto funciona como demonstração do fluxo.

## Funcionalidades

- Quiz com perguntas persuasivas em etapas
- Página de vendas
- Animações e transições entre as etapas
- Navegação entre páginas
- Interface responsiva com componentes reutilizáveis

## Tecnologias

- React
- TypeScript e JavaScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- React Router
- HTML e CSS
- Lovable Cloud

## Como rodar localmente

```bash
# clonar o repositório
git clone https://github.com/joota-tech/noites-de-paz-quiz.git
cd noites-de-paz-quiz

# instalar dependências
npm install

# iniciar em modo de desenvolvimento
npm run dev
```
